# Unstable과 하수도 위험 효과

공식 v4.0.2의 `Unstable.proc`은 적중 시 `Random.oneOf(randomEnchants)`를 한 번 호출한다. 14개 클래스의 선택 확률은 각각 1/14이다. 선택된 클래스의 원본 `proc(weapon, attacker, defender, damage)`가 별도의 발동 조건을 평가한다. Projecting은 사정거리를 바꾸며 이 추첨에 들어가지 않는다. 이전 Kinetic의 잉여 피해는 원래 순서로 떼어 마지막에 더한다.

아래에서 L은 음수를 0으로 제한한 무기 레벨, M은 원본 공격자의 procChanceMultiplier이다. 표의 발동 기초 확률에는 코드에서 정한 M이 곱해진다. 두 좌석 시험은 자연 생성된 421의 석상 무기로 각 좌석을 번갈아 공격한다. 개별 분기 시험에서만 별도 RNG 스택의 초기값으로 최초 선택과 발동 롤을 재현했다. 석상의 실제 적중 판정과 연속 무작위 추첨은 별도 시험이다.

각 효과의 출발점은 같은 한 번의 원본 무기 공격이다. 별도의 플레이어 턴을 발급하지 않는다. 지속시간은 원래 Buff·Blob Actor가 소비한다. 순간 tracker와 Pushing은 다음 입력 경계에서 처리하고, 남은 버프·지형·블롭은 기존 Hero/Level 번들에 들어간다. 일시적 연출 도중의 중간 세대를 발행하지 않는다. 효과마다 모든 중간 상태를 독립 JVM에서 저장 시험한 것은 아니다.

공격자·피해자는 원본 Char 인자로 전달한다. Eldritch의 단일 영웅 관찰자 비교, Shocking의 표시·음향, Blazing·Blocking·Grim·Vorpal·Blooming의 스프라이트 연출, Pushing의 카메라·완료 콜백과 함정의 원본 영웅 시야 의존성을 협동에서 분리했다. 실제 피해·충돌·일정은 호스트가 결정한다. 공개 모델은 해당 좌석에서 직접 보이는 셀의 지형·함정·블롭 및 자기 버프만 갱신한다.

## S2의 입력 및 확정 경계

`Level.occupyCell → pressCell → Trap.trigger`는 일반 이동과 강제 이동이 공유한다. 원래부터 보이는 WornDartTrap은 숨김 요청에도 보인다. 원본 표적 선정·Ballistica·방어 굴림·VFX 우선순위의 피해 Actor를 사용한다. 숨겨진 OozeTrap은 원래의 탐색으로 발견할 때까지 일반 바닥으로 투영된다. 시험에 사용한 소환·양떼·순간이동·경보·부식 점액 및 화염·냉기·전격·독가스·혼란가스는 원래 효과를 실행한다. 10종의 확장 시험은 생성된 방에 정확한 원본 클래스를 배치한 시험이다.

화염·빙결에 의한 고기 변환은 새 물리적 ID에 기존 귀속을 이관한다. 폭탄 연쇄, 물약 파괴, 추락·분기·식물·우물·미지원 함정 착지는 후속 검증 대상이다. 실제 처리가 이미 시작된 후 지원 범위를 벗어나면 성공을 확정하지 않고 마지막 정상 세대를 보존한다. 함정의 모든 아이템·챌린지 상호작용까지 검증한 범위에는 들어가지 않는다.

## 석상 및 황금 미믹

`Statue.attackProc`는 실제 장비의 원본 명중·피해·방어·사정거리와 `Weapon.proc`를 사용한다. `CoopSession.statueWeapon`은 검증한 기본 무기와 효과를 독립적으로 검사한다. 428 단검 Dirk/독성, 434 원형 방패/관성, 435 쇼트소드/사거리, 437 쇼트소드/흡혈, 421 시미터/불안정이 추가되었다. 이전 416·420·444도 계속 검사한다. 영웅 장착과 기술은 별도의 실행 경로다. ArmoredStatue 등 미검증 거주자는 계속 거부한다.

427·428의 GoldenMimic은 위장 중 실제 잠긴 상자와 동일한 공개 셀·입력 경로를 사용한다. HP·전리품·교전 경계·실제 몬스터 타입을 공개하지 않는다. 원본은 기본 미믹 레벨에 1.33배 반올림과 장비·지팡이 보상의 저주 해제, 해당 +0 보상의 50% 강화 기회를 적용한다. 고정 금화 지급 규칙은 없다. 처치·보상·귀속은 실제 생성품을 기준으로 검사한다.
