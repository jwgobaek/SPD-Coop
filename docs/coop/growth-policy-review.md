# 일반 방 성장 정책 검토

일반 방은 가면 OFF, 왕관 OFF, 마지막 타격 경험치로 저장한다. 운영 전환에는 별도 승인이 필요하다. 기존 저장을 열 때 기록된 정책과 잠긴 참가자 명단을 그대로 사용한다.

| 검토할 정책 | 운영 전환 전 확인할 동작 |
|---|---|
| 신규 방의 가면·왕관 각각 ROSTER | 보상 실물 ID 한 개를 소비하고 잠긴 각 좌석에 1회 권리를 기록한다. 선택·미사용·소비 완료를 새 JVM에서 대조하고 중복 요청은 원래 영수증을 반환한다. |
| 전투 불능과 최종 사망 | 행동 가능한 좌석만 선택한다. 재접속 좌석의 인증·미사용 권리와 이미 소비된 권리를 보존한다. 사망 후 재분배 여부는 별도 결정 대상이다. |
| 장거리 비콘 | 현재 개발 시험방에서 두 생존 좌석의 동의와 제안자 충전, 같은 분기 휴면 층 복원을 사용한다. 거절·종료·재시작과 착지 불가를 검사한다. 분기 간 귀환은 미지원이다. |
| 두 도적의 식량 | 한 상자의 귀속 결정과 각자의 독립 상자·한도를 별도로 비교한다. 단일 도적의 기존 동작을 유지한다. |
| 경험치와 생존 | 마지막 타격, 총량 분할, 적격 생존자별 지급은 격리된 안내기 표본에서 비교한다. 실제 획득량, 층 이동, 사망·회복과 행동 차이를 기록한다. |

개인 저장 이행·실물 소유권·재접속을 시험하고, 기본 효과만 지원하는 선택지는 실제 지원 범위를 안내한 뒤 신규 방 정책을 결정한다.
