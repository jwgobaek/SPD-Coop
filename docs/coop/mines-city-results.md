# 광산 분기와 드워프 도시

기준 소스 df645fc에서 기존 185개 JUnit을 다시 실행해 모두 통과했다. 본편 깊이 1~19와 대장장이 광산에 스키마 10 및 SYNC22를 사용한다. 이전 저장 스키마 1~9는 각각 원래 깊이 제한으로 읽는다.

| 시험 | 사용한 실제 경로 |
|---|---|
| 시드 571 GNOLL | 본편 12층의 원본 대장장이·곡괭이, 같은 깊이의 GnollGeomancer·Sapper·Guard, 원본 바위 방어·채굴과 보스 처치, 귀환 |
| 시드 570 CRYSTAL | 본편 13층에서 실제 CrystalSpire·Guardian·Wisp 광산에 진입, 곡괭이를 사용한 지형·보스 타격, 처치와 귀환 |
| 광산 저장 | 두 영웅의 출구 동의, 좌석별 탐험 기억, 실제 곡괭이와 DarkGold ID, 소유권, 채굴한 셀, 정산 후 재입장 제한 |
| 대장장이 | 광석 일곱 개면 350 favor, 광석 최대 2,000, 원본 보스 처치 시 1,000 추가. 원본 비용으로 곡괭이 회수, 현금화, 경화, 강화, 같은 소유자 장비 재련, 장비 제작·선택을 처리한다. 원본 v4.0.2 제작 보상은 감정된 상태로 지급한다. |
| 도시 | 16층 원본 상인·구매·판매·환매, GhoulLifeLink가 보관한 쓰러진 Ghoul의 ID와 실제 부활, Warlock이 양쪽 영웅에게 사용하는 원거리 공격과 Degrade. 572의 Imp 의뢰 수락, 16~19층 복귀·재방문과 다음 행동. |
| 호환성 | 실제 구버전 프로그램으로 만든 저장본을 별도 JVM에서 열었다. 스키마 8·9에서는 두 좌석의 인증, 기존 영수증 재전송, 다음 행동과 원본 저장본 보존을 확인했다. |
| Desktop | 두 원본 광산 및 도시 시장을 한국어·영어로 촬영했다. 시험용 위치에서 실제 좌석 공개 스냅샷으로 게임을 렌더링했다. |

두 광산 보스전은 위치를 배치하고 HP 1,500과 무기 +6을 사용했다. 원본 보스의 체력과 피해 규칙을 사용했다. 계단 표본은 같은 시드의 어떤 앞선 층에서 막혔는지도 기록한다. 16층 10/12, 17층 8/12, 18층 8/12, 19층 6/12에서 복귀·재방문 후 입력까지 성공했다. 연속 12개 중 20층과 21층은 원본 생성 조사만 수행했다. [계단별 측정](mines-city-stairs.tsv) · [원본 72개 층](mines-city-generation.tsv)

## 남은 작업

실제 v4.0.2의 새 Imp 의뢰는 VaultLevel에 들어가 EscapeCrystal을 사용한다. 기존 세이브용 토큰 의뢰 분기가 별도로 남아 있다. 신규 의뢰는 수락까지 지원한다. 금고 복귀 후 원본 보상 선택, Dwarf King의 도시 보스방 봉쇄·소환·생명 연결·보호막·지연 피해·왕관의 저장 경계가 다음 작업이다. 20층 운영과 21층 협동 진입은 닫혀 있다. 정상 시작 후 Tengu·DM-300·Dwarf King 처치 이력은 없다.
