## 생성 조사에서 확인한 범위

연속 시드의 원본 6·7·8·9층 초기 주민은 각각 5–9, 5–13, 7–17, 8–18개였다. 10층에서는 잠긴 전투를 개시하기 전 Tengu 객체를 PrisonBossLevel이 따로 보관하여 일반 몬스터 목록은 비어 있었다. 감옥 조사에 나타난 GeyserTrap, PoisonDartTrap, ToxicGasRoom.ToxicVent는 개별 효과가 미지원이다. 기존 BurningTrap·AlarmTrap 회귀를 유지했고 이번 체크포인트에서 신규 함정을 활성화한 수는 0이다. 표는 최종 APK 빌드와 함께 실행한 JUnit XML의 관측값이다. 별도 생성 실행과 비교하면 주민·방·함정·퀘스트·입장 판정은 일치했고 판매 품목 9행, 바닥 전리품 5행, 직렬화 크기 13행에 차이가 있었다. 원본 ShopRoom.ChooseBag은 동점 후보를 HashMap 순회로 고른다. 층 재방문은 실제 저장한 Level을 읽는다. 세 의뢰에서 두 보상 후보를 생성했을 때 관찰한 지팡이는 BlastWave, Corrosion, Corruption, Disintegration, Fireblast, Frost, Lightning, LivingEarth, MagicMissile, Regrowth, Transfusion, Warding의 12종이다. 이 지팡이들의 개별 시전·충전·귀속 및 보상 확정 검증은 후속 범위다.

## 구현과 수정 사항

- `CoopTrade.execute`와 원본 `WndTradeItem`, `Shopkeeper`가 실제 행동자·원본 가격·가방 공간을 검사한다. 거래 대상 종류와 소유권이 맞을 때만 현재 좌석의 견적을 사용한다. 영수증 발행과 재고·금액·시간 변경은 한 세대에서 이루어진다. 상점 자금 10,000과 거래 위치는 장애·화면 시험용 배치다.
- 원본의 최근 3개 FIFO와 공유 골드를 사용한다. 자기 판매품만 환매하는 정책은 임시 규칙이다. 가방 재편성, 절도, 특수 상품 및 구매한 장비의 미검증 능력은 미지원이다.
- `ItemOwnership`, `PinCushion`, `CoopSession` 및 `CoopFloors`가 단검의 물리적 보관 위치를 추적한다. `SeatProjection`과 `WndSeatTrade`는 좌석별 핸들·견적을 재검사한다. 다른 좌석의 환매품과 몬스터가 보관한 단검 목록은 발행하지 않는다.
- `Guard`와 `DM100`은 원본 전투 시간을 사용하며 협동 호스트에서 스프라이트 콜백을 기다리지 않는다. `CoopBoard`는 감옥 7층의 원본 타일과 몬스터를 표시한다. SYNC16, 저장 5, 4 MiB·휴면 레코드당 1,500,000바이트 한도를 적용한다.
- 검증 중 원본 미사일 세트 수량 상한을 넘긴 시험품은 원본 시작 수량으로 수정했다. 상점 확인 창에서 스냅샷 도착과 버튼 입력이 겹칠 경우 현재 차례와 견적을 다시 읽도록 수정했다. Desktop 시험도 호스트 입력 확정과 좌석 차례 복귀를 기다린 뒤 출구를 선택한다. 전멸 시 공개 종결 상태에는 self·지형이 없으므로 경로 시험은 원본 종결 영수증과 양쪽 좌석의 DEAD를 별도로 검사한다.

## 다음 시작점

같은 7층에서 시드 572의 MassGraveRoom·CorpseDust, 575의 RitualSiteRoom·CeremonialCandle, 577의 RotGardenRoom·RotHeart부터 진행한다. 세 방 모두 실제 원본 생성과 보상 후보를 표에 기록했다. 원본 Wandmaker.Quest의 두 지팡이와 의뢰물 소비를 영수증에 묶고, 두 좌석의 행동·실패·휴면 층·강제 종료를 검증한 뒤 NPC를 활성화한다. 이후 Necromancer의 소환과 감옥 후반의 함정·지팡이, 8·9층 왕복, Tengu 순으로 진행한다.

원본 PrisonBossLevel은 START, FIGHT_START, FIGHT_PAUSE, FIGHT_ARENA, WON을 저장한다. START·FIGHT_PAUSE에는 Tengu를 활성 몬스터 목록 밖에 보관한다. Tengu의 폭탄·화염·전격 장치와 storedItems, 두 영웅의 이동 및 보스 봉쇄를 검증한 후 10층을 열어야 한다. 가면을 소비한 소유자 한 명만 전직하는 후보와 파티에서 가면 한 개를 소비한 뒤 좌석마다 한 번 선택권을 기록하는 후보는 DECISIONS.md에 남겼다.
