# 지팡이 주입과 여섯 기본 직업

기준은 coop/phase8의 17bfa4a와 공식 v4.0.2다. 결투가와 성직자는 일반 방에서 선택할 수 있다. 전직과 갑옷 선택은 기존 OWNER·ROSTER 시험방에서 검증한다. 일반 방은 가면·왕관 모두 OFF이며 경험치는 마지막 타격 기준이다.

| 기능 | 실제 입력과 확인 범위 |
| --- | --- |
| 지팡이 주입 | 자신의 스태프에서 가방의 지팡이를 선택하고 확인한다. 호스트는 현재 시점의 가방 순서, 스태프 핸들 및 두 물품의 소유자를 검사한다. 확인을 닫으면 요청을 보내지 않는다. 감정한 물품만 원래 강화값을 표시한다. 지원하는 지팡이는 저주가 없다고 확인된 마력탄·충격파·화염 폭발이다. |
| 지팡이 보존 | 원본 0·1·2점의 실제 주입 및 레벨 상승을 양쪽 좌석에서 시험했다. 첫 보존 시 기존 내부 지팡이가 +0으로 반환되며 보존 카운터가 사용된다. 2점에서는 정상 레벨 상승으로 보존 기회가 회복된다. 스태프·새 내부 지팡이·반환 물품의 ID, 소유자 및 부분 충전을 저층부터 저장한다. 가방이 가득 찬 경우 새 지팡이가 차지했던 한 칸에 원래 지팡이를 반환했다. 저장 가능한 초과 수납 상태를 별도로 배치했을 때는 원래 소유자의 바닥 물품으로 떨어졌으며 복원 후 동료의 습득은 거부되고 원래 소유자는 같은 ID로 회수했다. |
| WildMagic | 자신의 사용 가능한 가방 지팡이로 원본 발사 목록을 추첨한 뒤 각 원본 효과와 부분 충전을 한 호스트 행동에 반영한다. 한 지팡이의 연속 두 발, 반대 좌석의 충전 보존, 갑옷 비용을 시험했다. 저주·수지 및 목록에 미지원 지팡이가 포함된 발사는 제한한다. |
| SpiritHawk | 소환은 원본 갑옷 충전 35와 한 턴을 소비한다. 소환자의 다음 명령은 무료다. 두 사냥꾼의 Actor와 소환자 ID, 재접속 후 명령, 한 좌석의 매만 관측한 원거리 지형의 공개 범위를 시험했다. |
| 원소 폭발 | 기존 마력탄에 더해 주입한 화염 폭발의 화염 지형 및 충격파의 강제 이동을 양쪽 마법사에서 검증했다. 지원 범위 밖으로 밀려날 수 있는 충격파는 확정 전에 제한한다. |
| 결투가 | 일반 로비의 양쪽 좌석에서 원래 레이피어와 투척용 쇠못 2개로 시작한다. 원본 돌진·공격·충전과 쇠못 투척, 석궁으로 바꾼 후 충전 사격의 실제 활성화를 지원한다. 다른 무기의 고유 능력, 투사·수도사 전직은 후속 범위다. |
| 성직자 | 일반 로비에서 원래 곤봉과 성서를 지급한다. 성서 메뉴에서 인도하는 빛을 조준하거나 신성 무기·신성 방어를 선택한다. 원본 공격·표식, 무기/방어 버프, 실제 소유자의 충전과 충전 Actor를 복원한다. 상위 주문과 전직은 후속 범위다. |
| 도적 성장 | 시험방의 원래 가면을 소비한 뒤 암살자의 망토 은신·준비·급습 또는 질주자의 이동·가속을 사용할 수 있다. 연막탄은 원본 충전·실명·이동을 적용한다. 몸 바꾸기 소환, 죽음의 표식과 그림자 분신은 지원하지 않는다. |
| 기타 특성 | 기존 세 직업의 2단계 특성은 지팡이 보존을 포함한 11/15종이다. RUNIC_TRANSFERENCE, IMPROVISED_PROJECTILES, ARCANE_VISION, HEIGHTENED_SENSES가 남았다. 숲지기의 Fadeleaf 층 이동은 미확정이다. |

## 재현

WandArtsTest는 양쪽 역할의 엔진 행동, 공개 메뉴, 물리적 ID와 복원을 확인한다. scripts/verify-dart-growth.py의 --actions에 imbue, volley, hawk, direct, lunge, spike, charged, light, ward, blessweapon, ambush, freerun, smoke를 사용한다. setup, HEAD 발행 후 강제 종료, 같은 좌석의 재인증과 영수증 재전송은 서로 다른 JVM에서 실행한다. MixedRoomStability에 -Dstability.wandArts=true를 사용하면 같은 JVM에서 성장 행동과 일반 행동을 섞는다.

시드 572의 exitcover 안내기는 저체력 추종자가 관찰한 동료를 우선 따라가고 전리품 탐색을 보류한다. 방 경계 기록은 관찰 전용이다. 이번 309행동 표본은 150점에서 전멸했다. 다른 표본의 기록과 합치지 않는다. 본편 570~581은 강화 배치로 12/12 일반 승리를 다시 확인했다. 정상 시작 승리 및 금고 최고 보상은 미달이다.

## 추가 실측

한국어와 영어 Desktop에서 자체 가방의 화염 폭발 지팡이 선택 창, 원본 확인 창, 취소 후 같은 상태 버전, 재선택·확정 결과를 촬영했다. 원본 효과 추가 시험은 양쪽 좌석에서 강화 +3 스태프에 지팡이를 두 번 주입하고 두 번째 보존이 거부되는 것, 미감정 강화값 비공개, 서로 다른 지팡이의 네 발이 복원 후 같은 피해·충전·RNG로 끝나는 것을 확인했다. 소환한 매는 1→2층, 저장·복원, 2→1층에서 같은 ID로 정확히 한 번 존재했다.

시험방의 암살자와 질주자는 가면을 통해 전직했다. 급습과 가속은 각 소유자의 원본 준비 또는 이동 버프를 소비한다. 도적 연막탄은 자신의 갑옷으로 선택·시전했을 때 실제 위치 이동, 주변 적 실명과 충전 소비를 확인했다.

동일 JVM 16개 방에서 신규 기능을 포함한 574개 행동을 확정했다. 거부 68회, 영수증 재조회·중복 16회, 게스트 재접속 32회였다. 행동 응답 중앙값/p95/p99는 22.502/75.039/107.728 ms였다. 1·8·16번째 방 종료 후 GC 힙은 각각 6,065,024 / 6,963,384 / 7,183,696바이트였다. 끝에서 방·Actor·LAN worker는 0, 스레드 7, FD 22, 소켓 1이었다. 이 표본만으로 장기 보유량이 수렴했다고 판정하지 않는다.

두 번째 금고 표본은 추종자가 마지막 목격 지점을 잠시 유지하고 선두가 문을 되돌아 나가는 횟수를 줄이는 안내기를 사용했다. 618개 확정 행동, 100점, 최종 HP 0/30이었다. 문 1367을 통한 양쪽 생존 퇴장, 퍼즐 및 4,000점은 달성하지 못했다.

기존 마법사·사냥꾼 정상 경로는 581에서 1,233입력, 1105에서 1,075입력으로 각각 Goo 처치 후 6층에서 전멸했다. 새 결투가·성직자 조합의 750입력 예산 시험은 세 XP 정책 모두 두 시드에서 2층에 도달했다. 581은 정책별 돌진 3회·인도하는 빛 13회, 1105는 각각 3회·10회였다. 좌석별 XP는 581에서 마지막 타격 5/11, 균등 8/8, 각각 지급 16/16이며 1105에서는 4/5, 5/4, 9/9였다. 후반 싱글플레이 대조군 및 정상 시작 승리는 미확보다.

두 마법사가 같은 방에서 각각 지팡이를 보존하고 복원한 뒤 원래 스태프 퀵슬롯이 같은 물리적 스태프를 가리켰다. 2점 마법사만 레벨이 올랐을 때 그 좌석의 보존 카운터가 해제되고 1점 마법사의 카운터는 그대로였다.

강화 받아치기 2점·콤보 9에서 같은 원본 스케줄러의 서로 다른 두 쥐가 한 방어 시간 안에 차례로 공격했다. 두 좌석 모두 두 적이 반격 피해를 받고 영웅 HP가 유지됐다. 첫 반격으로 적이 죽는 별도 배치에서도 두 번째 적의 반격 피해를 확인했다. 강화 콤보 도약으로 숨겨진 속박 함정에 착지하면 절름발이와 활성 함정이 남았고, 점액 함정에서는 점액 버프와 함정 비활성화를 확인했다.

속박된 결투가의 돌진 거부 경로에서 화면 카메라가 없는 권위 호스트의 예외를 재현했다. 화면 흔들기와 소리·공격 표시를 싱글플레이 연출 경로에 두고 실제 양쪽 좌석의 거부, 충전 보존, 동료·벽·구덩이에 막힌 착지, 속박 함정으로 정상 착지 후 공격을 회귀에 추가했다.

Cloud의 영어 Desktop에서 WildMagic 갑옷을 선택하고 적을 지정해 발사를 확정했다. 한국어 Desktop에서는 매 소환 뒤 소유자의 이동 명령을 입력하고 재명령 시 갑옷 충전이 유지되는 것을 확인했다. 서로 다른 매의 소환자·시야와 네 발의 지팡이별 결과는 엔진 및 TCP 시험에서 대조했다. 상위 특성 4점을 배치한 별도 시험에서는 실제 원본 여덟 발의 소모 총량이 8 × 0.5 × 0.67⁴와 일치했다. 지팡이 충전 부족은 갑옷과 RNG를 보존했다. 소환자 전투 불능 후 매 사망, 소환자 최종 사망 후 원래 시간 만료, 두 경우 모두 복원 후 매 Actor 소멸을 양쪽 역할에서 확인했다.

기존 네 직업 및 두 신규 직업을 조합해 결투가 또는 성직자가 포함된 순서 있는 20개 로스터를 실제 일반 TCP 방에서 시작했다. 신규 직업의 시작 퀵슬롯, 충전·수량, 행동권에 따른 메뉴와 게스트 재인증을 확인했다. 같은 JVM에서 490개 행동이 확정됐고 거부 90회, 중복 20회, 재접속 20회였다. 마지막 GC 후 힙 6,953,400바이트, 방·Actor·LAN worker 0, 스레드 7, FD 22, 소켓 1이었다. 이 20방의 중앙값/p95/p99는 13.997/32.295/58.494 ms였다.

별도 정상 TCP 비용 시험은 각 행동마다 좌석별 2회, 총 4회씩 측정했다. 명령·영수증 왕복 중앙값(ms)은 imbue 48.18, volley 66.59, hawk 65.89, direct 40.50, lunge 71.69, charged 60.62, light 88.68, ward 58.09, smoke 77.81였다. 개별 명령 크기 및 좌석별 공개 스냅샷 바이트 수는 배포 ZIP의 evidence/ability-cost.txt에 수록했다.

문 1367의 이전 447행동 표본에서는 게스트가 HP 2로 424번째 입력에서 1933→1934로 이동했다. 방장이 425번째 입력으로 1996번 출구를 비운 직후 게스트는 426번째 입력에서 1872번 다트로 이동해 428번째 입력으로 습득했다. 이번 세 번째 표본의 안내기는 직접 본 동료가 출구를 비우면 그 문을 잠시 기억하도록 했다. 시작 행동권과 위치가 기존 기록과 달랐고, 188행동·100점에서 전멸했다. 세 표본 모두 정상 양쪽 퇴장에는 실패했다.

공식 57a4e06의 Desktop JAR만 사용한 별도 마법사 대조군에서 실제 시야와 공격 경로로 지팡이를 조준했다. 581은 27입력 후 1층에서 사망했고, 1105는 1,250입력 예산을 소진했으며 마지막 상태는 2층·레벨 1·누적 XP 8·HP 12였다. 후반 성장 대조군은 아직 확보하지 못했다.

영어 Desktop에서는 결투가의 레이피어 메뉴에서 목표를 지정해 실제 위치 변화와 무기 충전 감소를 확인했다. 한국어 Desktop에서는 성서의 주문 목록을 열어 인도하는 빛을 선택하고 적에게 발사했다. 별도 엔진 시험에서 실명한 좌석의 두 칸 앞 빈 지점 돌진은 원본대로 충전 한 칸을 소비했으며 먼 적은 전후 공개 스냅샷에 나타나지 않았다.

## 저장과 복구

이전 배포 소스로 직접 작성한 스키마 15 한 건, 16 두 건, 17 두 건, 18 두 건을 새 JVM에서 복원했다. 가면·왕관 시험 정책, 도적 로스터와 종결된 Ascension을 포함한 7/7이었다. 스키마 19와 SYNC30으로 전달한 신규 행동 13종을 양쪽 역할에서 확정한 직후 실제 호스트를 종료했다. 새 프로세스가 원래 두 좌석을 인증하고 기존 영수증을 반환했다. 신규 26개와 이전 70개를 합해 서로 다른 복구 경계 96개를 확인했다. 장기 혼합 행동이나 반복 비용 측정의 횟수를 복구 경계에 합산하지 않았다.

## 후속 개발 시작점

1. 세 가지 지원 지팡이에서 현재 검증한 주입·발사·충전·보존 조합을 기준으로 다음 지팡이 하나의 원본 ZAP, 전투 마법사 근접 효과, ElementalBlast, WildMagic을 함께 검증한다. 저주 효과와 Wondrous Resin의 원본 발사 경계는 별도로 다룬다.
2. 남은 2단계 특성 네 종 중 ARCANE_VISION부터 감지 전용 정보와 직접 시야를 분리한다. 상대 좌석의 델타 및 완전 스냅샷까지 검사한 뒤 HEIGHTENED_SENSES에 적용한다.
3. 결투가 무기별 능력, 성직자 주문 및 도적의 DeathMark·ShadowClone을 이어간다. 일반 방 가면·왕관 정책은 각각 OFF로 저장한다.
4. 금고는 같은 실행에서 저체력 게스트의 출구 대기와 엄호를 검증한다. 447행동 표본의 423~428번째 공개 입력을 기준으로 비교하고, 다른 롤의 출구·생존·점수를 합산하지 않는다.
