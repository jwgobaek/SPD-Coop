# Imp 최종 정령과 아뮬렛 귀환

시작 커밋은 `f239c06`, 정령 체크포인트는 `c4b4e7b`, APK 소스는 `ecccda0`이다. 원본 v4.0.2의 본편 1~26층 가운데 지원되는 생성 조합과 두 광산을 사용한다. 일반 승리와 지상 귀환 승리는 서로 다른 영수증과 종료 상태를 갖는다.

## 금고

시드 572, branch 1의 18층에서 HP 600인 원본 VaultBossElemental이 생성됐다. 살아 있는 두 영웅이 방에 들어온 뒤 원래 경계에 접근하면 경고와 지연 소환, 문 봉쇄가 발동한다. 금고 안의 전투 불능 동료 처리와 두 좌석의 모든 장비별 저항 조합은 추가 시험이 필요하다. 특수 공격 좌표는 각 좌석이 볼 수 있는 칸만 전송한다.

원본 저장에서 빠졌던 세 속성의 남은 가중치와 약점 안내 상태를 보존한다. 가중치의 원소 수와 정수 범위를 검사한다. 정수로 읽던 추적 전격의 각도를 실수로 복원하고, 복원 중 붙는 버프를 새로운 공격으로 처리하던 경로도 고쳤다. 옛 싱글플레이 파일은 저장된 현재 속성으로 호환 초기값을 만든다. 과거 추첨 이력을 복원할 자료는 없다. 기존 협동 스키마 14에서는 최종 정령 전투가 운영 대상 밖이었다. 신규 협동 전투 저장에는 가중치가 필요하다.

FIRE·FROST·SHOCK에서 실제 공격을 진행하다 저장하고, 원래 JVM의 이후 입력을 새 JVM에서 재생해 다음 속성 선택, RNG, HP와 효과를 비교했다. 이번 최종 재실행에서는 각각 20·21·98개 연속 상태가 일치했다. 실제 전투로 봉쇄를 해제하고 원래 696번 칸의 ImpStatue 한 개를 획득했다. 원본 계산은 석상 보유 시 4,000점을 반환했다. 원본 반지 한 개를 선택해 탈출한 뒤 지급 전후 물리적 ID, 소유자, 강화값과 공유 자원을 확인했다.

원본 보상 허용 함수도 0, 49, 50, 499, 500, 999, 1,000, 1,001, 1,999, 2,000, 2,001, 3,999, 4,000, 4,050점 입력으로 따로 시험했다. 음식은 500점부터, 이 시험의 +0·+1·+2 반지는 각각 1,001·2,001·4,000점부터 허용됐고 탈출 수정은 전 구간에서 거부됐다. 이 숫자는 점수 함수의 경계 시험 입력이다.

이 승리는 원본 방에 영웅을 배치하고 체력 보너스 6,000과 장검 +3을 사용한 격리 시험이다. HP 보너스를 제거하고 금고 입장 시 받은 소지품 그대로 최종 방 앞에 배치한 별도 시험에서는 25·30 HP, 힘 10, 무기 없음으로 8행동 후 전멸했다. 정령의 남은 HP는 590이었다. 원래 금고 입구부터 각 좌석에 보이는 물품·몬스터·기억 지형만 이용한 추가 구역 시험에서는 91행동(이동 76, 공격 14, 습득 1) 후 100점에 전멸했다. 금고 입장 이후 HP·위치·아이템·점수를 주입하지 않았다. 이 경로의 실제 4,000점 목표는 FAIL이다.

시드 578의 자체 금고에 생성된 VaultShaman과 금고 전용 화염·냉기 정령의 실제 주문을 각각 양쪽 좌석에서 시험했다. 이들의 토큰, 시드 578 본편·광산·금고의 왕복, 두 분기 방문 후 26층 아뮬렛 영수증과 복원을 확인했다. 같은 시드 세대는 1,482,117바이트였다. 별도의 혼합 시드 용량 회귀는 이번에 1,488,489바이트였다. 이전 버전의 혼합 시드 실측은 1,488,218바이트였다.

## Ascension

26층에서 원본 아뮬렛을 얻고 계속하기를 선택해 25층으로 돌아온다. 두 영웅이 원본 위쪽 계단 범위에 있을 때 아뮬렛 소유자가 귀환을 제안하고 상대가 동의한다. 실제 이동에는 계단 동의가 적용된다. 하나의 원본 AscensionChallenge가 소유자에게 붙는다. 전투 중 이동 제약, 피해와 기존 보스층 회복은 각 영웅의 생존 상태에 적용된다. 원본 최고 귀환 깊이와 처치에 따른 스택 감소는 파티에서 한 번 갱신한다. 동료의 전투 불능과 부활, 24~1층 이동, 원본 지상 출구와 최종 종료를 배치형 시험으로 검증했다. 싱글플레이 랭킹 및 배지로 발행하지 않는다.

25→24층에서 시작한 배치형 실제 귀환과 정상 시작 전체 완주는 별도로 기록한다. 이번 두 정상 시작 TCP 경로는 시드 581이 1,233행동, 1105가 1,075행동 후 6층 전멸이었다. 둘 다 계단 동의 5회였다. 앞선 16개 표본의 Yog 승리 0회 기록을 보존한다.

## 다음 개발 시작점

1. 시드 572의 실제 입구에서 원본 토큰 문·레이저·거울·장비 수집에 필요한 공개 좌석 행동을 안내기에 연결한다. 최종 방에 좌표나 장비를 주입하지 않는 4,000점 완주, 쓰러진 동료가 있는 방 진입, 중간 점수 구간과 hazardFreebies를 각각 검증한다.
2. 시드 570의 23→24층 Acidic, 574의 23→24층 Greatshield/Kinetic과 나머지 석상 효과를 각각 양쪽 좌석에서 시험한다. 시드 578의 자체 금고 전체 퍼즐 완주를 진행한다.
