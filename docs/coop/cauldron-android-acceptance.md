# SYNC40 Android 인수

2026-11-27 GB2의 Android 15 MuMu 두 대에서 APK 빌드 커밋 `0998031843b59021e54fdf3d9d4b601eff9c9ce9`를 검사했다. Chromium 비로그인 다운로드와 데이터 보존 업데이트 뒤 양쪽 base.apk는 37,367,918바이트, SHA-256 `a684461eb4ac34e988153059ce8ada614aa689f2fd52b53ff4b0280453252797`이었다. 기존 인증서와 패키지, versionCode 922, DEX의 명시적 배열 형 변환을 확인했다.

| Android 15 부팅 | 역할 | 필수 시나리오 |
|---|---|---|
| 7867132f-4ba4-4a71-abe0-b096e52cdc07 | 방장 | 46/46 PASS |
| 8ce63420-1712-4ee2-a895-b5568acebf55 | 게스트 | 46/46 PASS |

기존 성서 선택 10건, 마법 부여 주문서 28건, STASIS 22건을 재실행했다. 솥은 역할별 16건, 전체 32건을 추가해 총 92/92였다. 시나리오별 저장 HEAD, 원래 영수증과 다음 영수증, 실제 화면, 속성별 관측표와 SHA-256은 대응 ZIP에 포함한다. 일반 화면 입력은 두 MuMu에서 실행했다. 중복·오래된 요청·상대 좌석 핸들은 동일한 Android 권위 호스트에 기존 시험 좌석으로 인증한 TCP 클라이언트에서 재전송했다. [필수 명세](android-acceptance-sync40.json)

두 역할에서 인접한 솥을 열어 자기 가방에서 미감정 자장가 주문서를 골랐다. 미리보기에는 룬석 자리표시자, 수량 2, 에너지 0이 표시됐다. 취소와 재선택을 거쳐 확정한 뒤 주문서가 감정됐다. 일반 가방에서는 주문서 1개가 소진됐고, 가득 찬 가방에서는 원래 3개 중 2개가 남았다. 각 가득 찬 시험방의 출력은 물리적 ID 44, 수량 2인 한 스택이었다. 소유자는 각각 플레이어 1·2였다. 두 앱을 다시 시작해 기존 좌석으로 인증하고 식량을 먹어 공간을 확보한 뒤 같은 ID를 회수했다. 독립된 두 방의 ID다.

각 역할에서 동일 Action ID 재전송은 최초 조합 영수증을 반환했다. 오래된 버전은 REJECT_VERSION, 상대에게만 공개된 가방 핸들은 REJECT_ITEM이었다. 거부 전후 권위 버전은 14였고 이후 실제 입력은 확정됐다. 초기 진단에서 조합 직전 BACKUP을 연 표본에는 재전송할 조합 영수증이 없었다. 조합·회수 영수증이 보존된 별도 시험방에서 중복·거부·다음 행동 전체를 다시 확인했다.

필수 시험용 20개 UUID의 양쪽 미결 요청은 모두 0개였다. 필수 구간의 Android 로그에서 VerifyError·LinkageError·치명적 GLThread 예외·프로세스 크래시·ANR은 각각 0건이었다. 독립적으로 수집한 앱 이벤트와 각 역할의 확정·후속 응답을 대조했다. 순환 버퍼 전체 과거 이력은 보존하지 않는다. 실제 SYNC39 시험 저장도 원래 두 좌석으로 SYNC40에서 재인증했다. 그 저장의 내부 스키마는 21이었고, SV 24에서 두 좌석 인증 후 26, 네 번의 실제 대기 후 HEAD와 SV 모두 30이었다.

모두 격리된 배치형 방 및 Windows 루프백 ADB 중계에서 수행했다. 실제 휴대폰 Wi-Fi·핫스팟과 후속 SYNC41 APK의 Android 인수는 NOT RUN이다. 구버전의 12종 주문서 호스트 조합 표본은 24/24였고, 이번 Android 조합 실측의 재료는 자장가 주문서다.

## 추가 실측

방장의 미감정 자장가와 게스트의 미감정 재충전 주문서를 실제 가방에서 읽었다. 각각 한 개가 소비됐고 원본 감정 상태가 false에서 true가 됐으며 READ_SCROLL 영수증이 남았다. 다만 **읽기 전 가방 상세창이 실제 이름과 설명을 노출했다**. 일반 읽기와 소비는 PASS, 읽기 전 상세 정보 비공개는 FAIL이다. 필수 92건의 솥 결과 미리보기에는 미감정 결과 자리표시자가 표시됐다. 이 추가 결함은 SYNC40 배포본에 남아 있다.

방장은 자장가 각인을 회수해 RECALL_INSCRIPTION 영수증을 받았다. 게스트는 가방에서 빠져 바닥에 있던 분해 지팡이(ID 25)를 자기 기억 목록에서 선택했다. 같은 방에서 성심 형상으로 발사한 뒤 표적 쥐의 HP가 200→187, 갑옷 충전 표시가 50→25로 바뀌었으며, 다음 방장 대기까지 HEAD와 SV가 6이었다. 실제 적 한 마리의 관통 광선 입력을 확인했다. 다중 표적 피해의 Android 표본은 별도로 남는다.

종료 시 두 설치본의 해시를 다시 확인했다. 두 MuMu가 타이틀 화면에 응답했고 GB2의 최종 CPU는 41%, 가용 메모리는 2,864/16,085 MiB였다. 이번 두 다운로드와 47821 시험 중계, 게스트 임시 ADB 연결 및 로그 수집 프로세스를 정리했다. 원래 호스트 ADB 연결은 남아 있었다. Windows 디스크에 개발 파일을 쓰지 않았다.
