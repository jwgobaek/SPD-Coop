## Android 15의 두 좌석

기본 Device-2의 ADB 주소는 127.0.0.1:5559이며 16448도 같은 부팅 ID였다. 보조 Device-2-1은 127.0.0.1:16480에서 다른 부팅 ID를 보고했다. 두 Android를 Windows 루프백에 제한한 ADB 중계로 연결했다. 사용자가 진행하던 방과 별개인 기존 마법사·사냥꾼 시험방을 사용했다.

## GB2 정리

시험방을 정상 저장하고 닫았다. 두 다운로드 파일을 배포 해시와 대조해 제거한 뒤 양쪽 Android에서 해당 경로가 비었음을 확인했다. 시험에서 추가한 호스트 forward와 게스트 reverse, 게스트 ADB 연결을 정리했다. 루프백 57955번 리스너는 0개였다. 기존 호스트 ADB와 Commander가 응답했다. 모든 APK·소스·검증 자료는 Cloud에서 처리했고, Windows에 프로젝트 파일을 만들지 않았다. 기기 개인 폴더는 조사하지 않았다.

종료 관측값은 CPU 37%, 가용 메모리 3,133 / 16,085 MiB, MuMuNxDevice 프로세스 2개였다. 두 MuMu는 실행 중이었고 시험 중 심각한 프리징은 관측되지 않았다.
